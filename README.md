# AI 3D 옷입히기

디미고 입시용 실적물.

옷 사진을 올리면 **Claude(Opus)** 가 사진을 분석하고, 그 결과로 사진을 가공해 **3D 마네킹**에 입혀 보는 웹 프로그램이다.
마우스로 돌려 보고, 말로 "검정색으로 바꿔 줘", "물방울 무늬 넣어 줘"라고 하면 옷이 바뀐다.

## 실행 방법

[Node.js](https://nodejs.org) 18 이상이 필요하다.

```bash
npm install
```

Claude API 키를 넣고 서버를 켠다. 키는 [Claude Console](https://platform.claude.com)에서 만들 수 있다.

```bash
# macOS / Linux
ANTHROPIC_API_KEY=sk-ant-... npm start

# Windows PowerShell
$env:ANTHROPIC_API_KEY="sk-ant-..."; npm start
```

브라우저에서 <http://localhost:3000> 을 연다.

API 키 없이 `npm start`만 해도 실행된다. 이때는 **수동 모드**로, 사진의 모양을 보고 기준점을 자동으로 추정하고
사용자가 점을 끌어서 맞춘다. 왼쪽의 샘플 옷 버튼으로도 바로 체험할 수 있다.

| 환경 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | (없음) | Claude API 키 |
| `CLAUDE_MODEL` | `claude-opus-5-5` | 사용할 모델 |
| `PORT` | `3000` | 서버 포트 |

## 사용법

1. 옷을 흰 배경(또는 단색 바닥)에 펼쳐 놓고 정면에서 찍은 사진을 왼쪽에 끌어다 놓는다.
2. Claude가 옷 종류·이름·핏·기준점을 분석하고, 배경을 지운 뒤 마네킹에 바로 입힌다.
3. 오른쪽 편집 패널에서
   - **Claude에게 리폼 요청**: 자연어로 색·무늬를 바꾼다.
   - **색 보정 / 무늬**: 슬라이더로 직접 바꾼다.
   - **기준점 맞추기**: 어깨·겨드랑이·소매끝·밑단 점을 끌면 3D 옷이 실시간으로 바뀐다.
   - **배경 지우기**: 배경이 덜 지워졌으면 민감도를 조절한다.
4. 상의·아우터·바지·치마·원피스·모자·신발을 겹쳐 입히고 `사진 저장`으로 결과를 내려받는다.

## 어떻게 동작하나

Claude는 그림을 직접 그리지 않는다. 대신 사진을 **읽고**, 프로그램이 쓸 수 있는 **숫자**를 돌려준다.
실제 픽셀 가공과 3D 표현은 브라우저가 한다.

```
옷 사진 ─▶ [서버] Claude API ─▶ 옷 종류, 이름, 핏, 배경색,
                                 기준점 좌표(어깨·겨드랑이·소매끝·밑단…), 외곽선
            │
            ▼
[브라우저]  ① 배경 지우기 (테두리에서 배경색을 번져 나가며 투명하게)
            ② 색 보정·무늬 (Claude가 정한 값 또는 슬라이더 값)
            ③ 3D 옷 메시 생성 → 기준점으로 사진을 몸에 매핑 → 마네킹에 입히기
```

### 사진을 3D 옷으로 바꾸는 방법

- 마네킹 몸 치수(목·어깨·가슴·허리·엉덩이 단면, 팔·다리 뼈대)를 코드로 정의하고, 같은 치수로
  몸보다 조금 큰 "관(tube)" 모양 옷 메시를 만든다.
- 각 정점이 사진의 어느 픽셀을 가져올지(UV)를 기준점으로 정한다.
  - 상의 몸판: `어깨–어깨–겨드랑이–겨드랑이`, `겨드랑이–겨드랑이–밑단–밑단` 두 사각형
  - 소매: `어깨–겨드랑이–소매끝 안–소매끝 바깥` 사각형을 팔을 따라 감싼다
  - 바지: 허리~가랑이 사각형 + 다리마다 가랑이~밑단 사각형
- 평평하게 놓인 옷의 폭은 입었을 때 **둘레의 절반**이라는 점을 이용해, 사진 속 폭으로
  헐렁함·치마 퍼짐·소매 굵기를 계산한다. 길이(기장·소매 길이)도 사진 비율로 정해진다.
- 배경을 지운 투명 부분은 잘려 나가므로(alphaTest) 메시를 넉넉하게 만들어도 보이는 모양은
  사진 속 옷 실루엣을 따른다. 목둘레·민소매도 이렇게 자연스럽게 생긴다.
- 등판에는 앞판 사진의 로고가 거울처럼 비치지 않도록, 각 가로줄을 그 줄의 대표 색으로 칠한 이미지를 쓴다.

### Claude를 쓰는 부분

- `prompts.js`: 지시문과 응답 JSON 스키마. **구조화된 출력(structured outputs)** 으로 항상
  스키마에 맞는 JSON을 받는다.
- `server.js`: API 키를 서버에만 두고 브라우저 요청을 Claude에 전달한다.
  - 옷 분석: `/api/analyze` — 이미지 + 크기 → 종류, 기준점 좌표, 외곽선 등
  - 리폼 요청: `/api/edit` — "빨간색으로" → 색상 회전·채도·밝기·덧칠·무늬 값
  - 안전 분류기가 요청을 거절하면 서버 쪽에서 다른 모델로 다시 시도하는 `fallbacks: "default"`를 켜 두었다.

## 파일 구조

```
server.js                 Node 서버 (정적 파일 + Claude API 중계)
prompts.js                Claude 지시문과 응답 스키마
public/
  index.html, style.css   화면
  js/main.js              3D 장면, 옷장, 편집 패널
  js/mannequin.js         마네킹 치수와 메시, 관 모양 메시 생성기
  js/garments.js          기준점 → 3D 옷 메시 (상의·소매·바지·치마·모자·신발)
  js/imageproc.js         배경 지우기, 색 보정·무늬, 기준점 자동 추정
  js/keypoint-editor.js   기준점 드래그 편집기
  js/samples.js           체험용 샘플 옷 (캔버스로 직접 그림)
```

## 한계와 다음 단계

- 정면 사진 한 장으로 만들기 때문에 등판은 앞판을 바탕으로 추정한다. 뒷면 사진을 따로 받으면 더 정확해진다.
- 옷은 몸을 감싸는 관 모양이라 주름·찰랑임 같은 천 시뮬레이션은 없다.
- 이미지 생성 모델을 연결하면 "로고 추가"처럼 필터로 못 하는 편집도 할 수 있다.
